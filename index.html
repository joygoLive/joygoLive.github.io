What has shipped so far

Fields that share nothing with each other — quantum infrastructure, exercise coaching, an on-chain raffle — already running rather than described. Each was built here and is operated here: not licensed, not resold.

UQH

Beta
Universal Quantum Hub · Quantum computing

Vendor-neutral middleware for quantum computing. Write in the SDK you already use, and reach every connected processor through one pipeline — analysis, optimization, noise simulation, error mitigation, QEC, and cost estimation before you submit.

  • Nine SDK frameworks, eight hardware vendors, one interface
  • Rank devices on evidence before spending QPU time
  • UI, REST API, CLI, and an MCP server for AI agents

AMC

In development
AI Motion Coaching · Community sports

Real-time exercise-form coaching from a single phone camera. A trainer's judgment criteria encoded as joint-angle rules, normalized against your own body baseline — so the feedback names what to fix instead of scoring a similarity you cannot read.

  • Runs on the device — no video leaves the phone
  • One spoken cue during the set, a full report after it
  • Reps it could not judge are named, never quietly counted

BOR

Testnet
Blockchain On-chain Raffle · Base

An on-chain raffle where 90% of ticket sales become the prize. The 10% fee is a constant compiled into the contract, and the drand round each future draw will use is already determined — so the draw can be checked rather than trusted.

  • National lotteries return about 50%. BOR returns 90%
  • No setter for the fee, no proxy to swap the logic
  • BLS12-381 beacon verification on-chain, against RFC 9380 vectors

Where each one actually stands
  • UQH is in beta and open to use. What costs nothing to run needs no credential at all; quantum processor time and AI calls run on credentials you register yourself. Being in beta means the surface can still move — features and limits are not frozen yet.
  • AMC is in development — an MVP under field tuning with community sports organizations. Not open to the public yet.
  • BOR runs on the Base Sepolia testnet and is not audited by a third party. It is a raffle, not an investment: the expected value of a ticket is below what it costs.
